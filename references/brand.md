# Firecracker identity

## Concept

Different perspectives. One shared spark.

서로 다른 자리에서, 하나의 불꽃을 바라보다.

A specification, architecture guide and runbook see a project from different places. Keep their distinct purposes while aligning them with the accepted decisions applicable to their scope. Fireworks represent shared direction and illumination, not destruction or deletion.

## Visual language

Use a midnight sky, generous negative space, vivid radial bursts and fine trajectories. Let one dominant burst organize each composition. Avoid a field of equally loud fireworks behind body text. Document outlines retain different positions and colors, connected to the shared light.

| Token | Color | Role |
| --- | --- | --- |
| Midnight | #090B18 | Brand covers and dark report background |
| Warm white | #FFF4E7 | Primary text on dark backgrounds |
| Ember | #FF6338 | Brand accent and focal details |
| Gold | #FFCB68 | Spark centers and highlights |
| Pink | #FF57B0 | Secondary burst |
| Violet | #A88BFF | Secondary burst |
| Cyan | #60E7F0 | Secondary burst |
| Muted text | #BEBBD0 | Supporting text on midnight |

Use decorative colors for marks and borders, with high-contrast body text. Indicate severity in words as well as color. Use static graphics by default; avoid flashing. Preserve clear tables, citations and code blocks in reports. Do not decorate source excerpts or command strings.

## Assets and copy

- `assets/hero.svg`: GitHub README cover; use relative paths so repository downloads work.
- `assets/icon.svg`: compact radial firework mark.
- Product: **Firecracker**. Skill name and command: **firecracker**, `$firecracker`.
- English: **Different perspectives. One shared spark.**
- Korean: **서로 다른 자리에서, 하나의 불꽃을 바라보다.**
- Functional line: **Find the drift. Follow the evidence.**

Use the metaphor in introductions and transitions only. Keep findings literal: contradiction, stale guidance, unresolved decision, partial review, deletion candidate. Never replace evidence or inspection coverage with celebratory language.

Apply this identity to Firecracker's own documentation and requested report presentation. Do not redesign audited project documents, insert fireworks into every file, or change product terminology solely to match this brand.
